# ChromaFlow

**All your lighting. One beautiful app.** A Windows and macOS app that runs your lights together: Govee, Philips Hue, WLED, QMK/VIA keyboards (like the XVX M67 Jadestone and Redragon's VIA models), and PC parts through OpenRGB.

## Download

Get the newest version from **[Releases](https://github.com/leopoldobruzuall-ai/ChromaFlow/releases/latest)**:

- **Mac** (Apple chip, M1 or newer): `ChromaFlow-<version>-mac-arm64.dmg`
- **Windows** (64-bit Windows 10 or 11): `ChromaFlow-<version>-win-x64.zip`

These are early test builds, and they aren't signed yet:
- **Mac:** open the app once, click **Done**, then go to System Settings › Privacy & Security and click **Open Anyway**.
- **Windows:** extract the zip first. If SmartScreen appears, click **More info › Run anyway**.

## What works

| Works now | Not yet |
|---|---|
| Govee Wi-Fi lights with LAN Control | Monster Smart lights |
| Philips Hue (through a Hue Bridge) | GravaStar (unless OpenRGB lists the model) |
| WLED | Nanoleaf, Bluetooth-only lights |
| QMK/VIA keyboards over USB (whole-keyboard color) | |
| PC parts and Redragon keyboards through [OpenRGB](https://openrgb.org) | |

Everything runs on your local network. There's no account and no cloud.
